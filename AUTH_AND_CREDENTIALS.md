# Wave Connector — Authentication & Credentials

## Principle
All Wave access tokens are stored strictly in Imperal encrypted secret storage (`wave_connections`). Tokens are masked in panel displays and sanitized from runtime logs.

## Setup Instructions
1. Log in to Wave at https://next.waveapps.com.
2. Go to **Manage your Profile > Integrations > API Access**.
3. Create a **Full Access Token**.
4. Retrieve the **Business ID** from your organization URL or account settings.
5. Enter credentials into the Imperal connection sidebar.
