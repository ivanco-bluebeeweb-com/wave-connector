# Wave Connector — UI Component Plan

## Layout Standards
- **Sidebar (`wave_sidebar`):**
  - Left dock slot (`slot="left"`).
  - Explicit vertical stretch (`align="stretch"`).
  - Form inputs with clear labels, contextual placeholders (`placeholder="e.g. QnVzaW5lc3M6..."`).
  - Help modal trigger for setup instructions.
- **Settings Panel (`__panel__wave_settings`):**
  - Multi-connection switcher and active account indicator.
