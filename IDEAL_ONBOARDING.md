# Wave Connector — Ideal Onboarding

## User Journey
1. **Discovery:** User opens Wave Accounting connector in Imperal.
2. **Setup:** Guided modal provides exact navigation path to generate a Full Access Token in Wave.
3. **Verification:** System performs a lightweight test query (`query { user { id defaultEmail } }`) and validates `businessId`.
4. **Active Operation:** User manages invoices, customer records, bills, and views cash flow summaries directly from Imperal.
